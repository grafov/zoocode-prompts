# zoocode-prompts

Modes and skills for ZooCode (formerly RooCode) and possibly for Cline as well.
The modes and skills are just prompts for an LLM but specially formatted in
YAML. 

## Modes list

### 🔍 Code Review — [`codereview`](modes/codereview.yaml)

Thorough code review of changes in a project repository. Compares branches,
assesses code quality, security, and architectural consistency.

### 🔬 R&D Researcher — [`rnd`](modes/rnd.yaml)

Web research with project applicability evaluation. Investigates technologies,
libraries, and approaches before committing to implementation. Produces
structured research reports with adaptation strategies.
